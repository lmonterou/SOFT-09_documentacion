# SOFT-09_documentacion
Repositorio de documentación para la Práctica II - Uso de Git y GitHub

**Curso:** 
SOFT-09: Introducción a la ingeniería del software (Universidad CENFOTEC).

**Propósito de la práctica:** 
Aplicar los conocimientos teóricos sobre control de versiones mediante el uso de Git y la plataforma GitHub. El objetivo es adquirir destrezas técnicas en la creación, manejo y sincronización de repositorios de software, simulando un flujo de trabajo profesional.

**Descripción del contenido:** 
Este repositorio académico contiene la configuración inicial del proyecto y un archivo de código fuente básico (`HolaMundo.java`). Este archivo no pretende ser una aplicación funcional compleja, sino que se utiliza estrictamente como material de apoyo para practicar el control de versiones, registrar cambios (commits) y subirlos a la nube (push).
